# CopyMody

Theos Tweak - Clipboard Manager for **RootHide** (Relaxin) on **iOS 18.7** (arm64e).

## Features (planned)
- Automatic clipboard monitoring & history
- Quick access floating UI from keyboard
- One-tap paste + history management

## Build
Requires Theos with RootHide scheme support.

```bash
make package
```

## Status
Initial skeleton - first successful build pending.
